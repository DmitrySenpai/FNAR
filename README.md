# Five Nights at Rooster (FNAR)

**Версия:** 1.0.0 (релиз-кандидат; публичный выпуск ожидает ручного QA и проверки прав на ресурсы).

FNAR — браузерная хоррор-игра на выживание с наблюдением за офисом из комнаты охраны. Игроку необходимо продержаться от полуночи до 6:00 AM, следя за камерами и защищая два входа от четырёх петухов.

## Играть

**GitHub Pages:** https://dmitrysenpai.github.io/FNAR/index.html

Игра загружается в браузере без установки. При первом запуске выберите язык, прочитайте предупреждение и дождитесь подготовки ресурсов. Первый запуск может занять больше времени из-за загрузки камер, видео и аудио; повторные запуски могут использовать CacheStorage. Если один из обязательных ресурсов не загружается, можно повторить загрузку без обновления страницы.

**Локальный запуск:** проект можно обслуживать простым статическим HTTP-сервером из корня репозитория, например `python -m http.server 8000`, затем открыть `http://localhost:8000/`. При открытии через `file://` некоторые браузерные функции могут быть ограничены.

## Возможности

- Семь игровых ночей; каждая смена — 360 секунд активного игрового времени.
- Четыре противника C1–C4, девять камер наблюдения, двери и освещение.
- Наблюдение за CAM 08, влияющее на C3.
- Отдельные происшествия и реклама вымышленной системы Door XP / Net Video 3.0, включая Chicken.exe.
- Телефонные звонки, редкие атмосферные события, звуки и видеоскримеры.
- Разблокируемые дополнительные ночи, Custom Night с AI 0–20 для каждого петуха.
- Сохранение прогресса и единственный регулятор общей громкости.
- Интерфейс на **русском, английском и японском**. Аудиозаписи телефонных разговоров остаются русскоязычными; перевод показан в субтитрах.

## Управление

| Действие | Управление |
| --- | --- |
| Осмотр комнаты | Мышь / движение пальцем; стрелки или A / D |
| Левая / правая дверь | 1 / 2 |
| Левый / правый свет | Удерживать Q / E |
| Камеры | C или кнопка под экраном |
| Выбор камеры | 1–9 при открытом планшете |
| Центрировать обзор | R |
| Пауза / продолжить | Esc или P |
| Отключить / включить звук | M, либо кнопка 🔊 / 🔇 в паузе |
| Громкость | Ползунок в меню паузы, мышью, касанием либо стрелками |
| Полноэкранный режим | F либо кнопка ⛶ |
| Настройки обзора | H либо кнопка ⚙ |

Во время телефонного разговора игровое время приостанавливается; звонок можно пропустить соответствующей кнопкой.

## Сохранения

Прогресс и язык записываются в браузерные cookie / локальное хранилище. В частности, используются ключи `kokhinhin_unlocked`, `kokhinhin_complete`, `kokhinhin_custom_complete`, `kokhinhin_custom_20202020`, `kokhinhin_custom_ai`, `kokhinhin_lang`, `kokhinhin_office` и `fnar_audio_settings`. Очистка данных сайта браузером может удалить прогресс; обновления игры не должны очищать эти данные.

## Требования и ограничения

Современный браузер с JavaScript, HTML5 Audio/Video, Canvas/WebGL и поддержкой современных CSS. Web Audio API используется для ускоренного воспроизведения коротких звуков при его доступности; есть резервное воспроизведение через HTML Audio. Постоянное кэширование требует доступности CacheStorage, но отказ в доступе к кэшу не должен блокировать игру сам по себе. Необходим звук для телефонных разговоров и эффектов; в браузере воспроизведение может требовать действия пользователя.

Не все сочетания устройств, видеокодеков, версий браузеров и мобильных ориентаций подтверждены ручным тестированием. Наиболее требовательные режимы содержат несколько аудио-, видео- и графических эффектов.

## Разработка и проверки

Статический проект на HTML, CSS и JavaScript. Запуск регрессионного набора локально (Node.js 22 или совместимая версия):

```sh
node --test tests/*.test.cjs
```

Обязательные тесты и проверка существования ресурсов должны завершиться успешно до автоматической публикации на GitHub Pages.
