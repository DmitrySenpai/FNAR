## 🇯🇵 日本語

### ゲームについて

**Five Nights at Rooster's（FNAR）** は、夜間警備員となってオフィスを守る、ブラウザ向けのホラーサバイバルゲームです。

深夜 **12:00 AM から 6:00 AM** まで、監視カメラで４羽のニワトリの動きを確認し、左右のドアと照明を使って生き残りましょう。電力には限りがあるため、使いすぎに注意してください。

### 主な特徴

- **全７夜**のチャレンジ。１夜のプレイ時間はゲーム内で約 **360 秒**。
- **４羽のニワトリ（C1〜C4）** がそれぞれ異なる行動をとります。
- **９台の監視カメラ**、左右のドア、照明、電力管理。
- 懐かしいパソコン風の架空システム **Door XP / Net Video 3.0**。広告、システム障害、**Chicken.exe** などのイベントも登場。
- 電話、ジャンプスケア、まれに発生する不気味な演出。
- 進行状況の保存、**Custom Night**（各ニワトリの AI レベルを 0〜20 で設定）、マスター音量の調整。
- UI は **日本語・ロシア語・英語** に対応しています。

> **音声について：** 電話の録音音声はロシア語です。日本語と英語では字幕で内容を確認できます。

### 操作方法

| 操作 | キー / 方法 |
| --- | --- |
| 視点移動 | マウス・タッチ操作、A / D または ← / → |
| 左 / 右のドア | 1 / 2 |
| 左 / 右のライト | Q / E を長押し |
| 監視カメラを開く / 閉じる | C、または画面のカメラボタン |
| カメラを切り替える | カメラ表示中に 1〜9、または CAM ボタン |
| 視点を中央へ戻す | R |
| ポーズ / 再開 | Esc または P |
| ミュートの切り替え | M |
| 全画面表示 | F |
| 視点設定 | H |
| 音量調整 | ポーズメニューの「音量」スライダー |

### 起動とセーブ

インストールは不要です。上の **「ゲームをプレイ」** からブラウザで起動し、言語を選択して警告を確認したら、初回の素材読み込みが完了するまでお待ちください。

プレイの進行状況・選択した言語・音量はブラウザ内に保存されます。ブラウザのサイトデータを削除すると、セーブデータが消える場合があります。

## 🇷🇺 Русский

### Об игре

**Five Nights at Rooster's (FNAR)** — браузерный хоррор на выживание, в котором вы играете за ночного охранника офиса.

Ваша задача — продержаться с **12 AM до 6 AM**, наблюдая за четырьмя петухами через камеры. Закрывайте двери и включайте освещение, когда это необходимо, но расходуйте электричество осторожно.

### Особенности

- **7 ночей**, продолжительность смены — около **360 секунд** игрового времени.
- **4 петуха (C1–C4)** с разным поведением.
- **9 камер наблюдения**, две двери, освещение и ограниченный запас электричества.
- Вымышленная система **Door XP / Net Video 3.0**: реклама, сбои и **Chicken.exe**.
- Телефонные разговоры, скримеры и редкие атмосферные события.
- Сохранение прогресса, **Custom Night** с настройкой ИИ 0–20, единый регулятор громкости.
- Интерфейс на **японском, русском и английском** языках.

> **Озвучка:** телефонные разговоры записаны на русском. Для японского и английского языков предусмотрены субтитры.

### Управление

| Действие | Клавиша / способ |
| --- | --- |
| Осмотр комнаты | Мышь, сенсорное управление, A / D или ← / → |
| Левая / правая дверь | 1 / 2 |
| Левый / правый свет | Удерживать Q / E |
| Открыть / закрыть камеры | C или кнопка камер |
| Выбрать камеру | 1–9 при открытых камерах или кнопки CAM |
| Вернуть взгляд в центр | R |
| Пауза / продолжить | Esc или P |
| Включить / отключить звук | M |
| Полноэкранный режим | F |
| Настройки обзора | H |
| Громкость | Ползунок в меню паузы |

### Запуск и сохранения

Игра запускается **непосредственно в браузере**, без установки. Откройте ссылку **«Играть»** выше, выберите язык, подтвердите предупреждение и дождитесь загрузки игровых ресурсов.

Прогресс, язык и громкость сохраняются в браузере. При удалении данных сайта сохранения могут быть потеряны.

## 🇬🇧 English

### About the game

**Five Nights at Rooster's (FNAR)** is a browser-based survival horror game where you work as a night security guard in an office.

Survive from **12 AM to 6 AM** by tracking four roosters through the surveillance cameras. Use the doors and lights to defend yourself, but watch your limited power supply.

### Features

- **7 nights**, each lasting approximately **360 seconds** of active in-game time.
- **4 roosters (C1–C4)** with distinct behaviors.
- **9 security cameras**, two doors, lights, and power management.
- The fictional **Door XP / Net Video 3.0** system, complete with ads, system malfunctions, and **Chicken.exe**.
- Phone calls, jumpscares, and rare atmospheric events.
- Saved progression, **Custom Night** with individual AI levels from 0–20, and a single master volume slider.
- Interface localization in **Japanese, Russian, and English**.

> **Voice-over:** Phone call recordings are in Russian; Japanese and English subtitles are available.

### Controls

| Action | Key / input |
| --- | --- |
| Look around | Mouse, touch controls, A / D, or ← / → |
| Left / right door | 1 / 2 |
| Left / right light | Hold Q / E |
| Open / close cameras | C or the camera button |
| Select camera | 1–9 while viewing cameras, or the CAM buttons |
| Center view | R |
| Pause / resume | Esc or P |
| Mute / unmute | M |
| Fullscreen | F |
| View settings | H |
| Master volume | Slider in the pause menu |

### Playing and saves

No installation is required. Open **“Play Now”** above, select a language, accept the content warning, and allow the initial assets to load.

Progress, language selection, and volume settings are stored in your browser. Clearing site data may remove your saves.
